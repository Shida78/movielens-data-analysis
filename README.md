# Анализ данных: MovieLens и California Housing

Учебный проект по обработке и визуализации данных на Python
(pandas, matplotlib, seaborn), выполнен в Google Colab.

## Что внутри

**MovieLens 1M** (около 1 млн оценок фильмов)
- объединение трёх таблиц (фильмы, оценки, пользователи) через merge;
- фильмы с 250+ оценками: средний рейтинг у мужчин и женщин;
- фильмы с наибольшей разницей оценок между мужчинами и женщинами
  (например, «Dirty Dancing»: 3.79 у женщин против 2.96 у мужчин);
- средний рейтинг жанров по возрастным группам (тепловая карта).

**California Housing**
- корреляционная матрица признаков и цены жилья (тепловая карта).

## Запуск

Блокнот: `movielens_analysis.ipynb`. Лучше всего открыть его в Google Colab
и выполнить ячейки по порядку.

Данные MovieLens 1M в репозитории не хранятся (лицензия не разрешает их
распространять): блокнот сам скачивает их с grouplens.org в папку `ml-1m`
и берёт оттуда. California Housing подгружается из scikit-learn.
Для запуска дополнительных действий не нужно.

Источник данных: grouplens.org/datasets/movielens/1m/
